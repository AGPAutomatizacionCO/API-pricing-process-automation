## Al subir cambios a GitHub (obligatorio)

Cada subida dispara revisiones automáticas que gastan minutos de GitHub de toda la organización.

- Antes de subir, corre las pruebas del proyecto en local. Si fallan, corrige; no subas "para ver si pasa".
- Si ya hay un PR abierto de esta tarea, sube los commits ahí; no abras otro.
- Fusiona solo cuando la revisión del PR esté en verde.
- Si la persona pide subir después de cada ajuste pequeño, sugiérele juntar los cambios y subirlos al terminar la tarea.
- Si cambias algo en `.github/workflows/`, cumple la [norma de Actions del kit](https://github.com/AGPAutomatizacionCO/agp-ai-governance-kit/blob/main/NORMA-GITHUB-ACTIONS.md).
